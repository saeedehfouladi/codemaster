# CodeMaster Landing Page

A modern educational landing page built with Next.js and Tailwind CSS.

## Features

- Next.js App Router
- Tailwind CSS
- Responsive Design
- Modern UI Components
- Reusable Component Structure
- Optimized for Performance

## Tech Stack

- Next.js
- React
- Tailwind CSS
- JavaScript

## Installation

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view the project.

## Project Purpose

This project was created as a learning and practice exercise to improve my skills in:

- Next.js
- Tailwind CSS
- Component Architecture
- Responsive Design
